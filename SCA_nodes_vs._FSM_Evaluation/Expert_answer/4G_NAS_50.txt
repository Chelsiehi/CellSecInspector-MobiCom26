Event ID: 18 (Derived from Section 4.2)
Sentence: "During the EPS attach procedure, the network can activate a default EPS bearer context (i.e. if the UE requests PDN connectivity in the attach request). Additionally, the network can activate one or several dedicated EPS bearer contexts in parallel for PDN connections of IP or Ethernet PDN type. To this purpose the EPS session management messages for the default EPS bearer context activation can be transmitted in an information element in the EPS mobility management messages. In this case, the UE and the network execute the attach procedure, the default EPS bearer context activation procedure, and the dedicated EPS bearer context activation procedure in parallel. The UE and network shall complete the combined default EPS bearer context activation procedure and the attach procedure before the dedicated EPS bearer context activation procedure is completed. If EMM-REGISTERED without PDN connection is not supported by the UE or the MME, then the success of the attach procedure is dependent on the success of the default EPS bearer context activation procedure. If the attach procedure fails, then the ESM procedures also fail"
Start State: UE initiates the EPS attach procedure, and the network is ready to process the attach request.
Condition: The UE requests PDN connectivity in the attach request, and the network supports the activation of default and dedicated EPS bearer contexts.
Action: The network activates a default EPS bearer context and may activate one or several dedicated EPS bearer contexts in parallel. EPS session management messages for default EPS bearer context activation are transmitted within EPS mobility management messages. The UE and network execute the attach procedure, default EPS bearer context activation, and dedicated EPS bearer context activation in parallel. The combined default EPS bearer context activation and attach procedure must complete before the dedicated EPS bearer context activation is finalized. If EMM-REGISTERED without PDN connection is not supported, the attach procedure's success depends on the default EPS bearer context activation. If the attach procedure fails, the ESM procedures also fail.
End State: The UE is attached to the network with a default EPS bearer context activated, and optionally, one or more dedicated EPS bearer contexts are activated. If the attach procedure fails, the UE remains detached, and no ESM procedures are completed.
