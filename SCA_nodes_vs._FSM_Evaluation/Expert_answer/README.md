## SCA Sample Format

Each text record contains `Event ID`, `Sentence`, `Start State`, `Condition`, `Action`, and `End State`. Event headers may also contain source-section information. Some records describe headings or document structure and therefore contain placeholder fields.

The three text files contain the expert-reviewed reference records used to evaluate SCA extraction across 4G NAS, 5G NAS, and 5G RRC. They can be used to inspect the expected SCA output structure and compare outputs produced by different language models.


## Expert Label Format and Counts

The CSV header is:

```csv
rater_1,rater_2
```
Each subsequent row contains one pair of `Pass` or `Fail` judgments independently assigned by the two domain experts.


## Intended Use

Use the CSV files to reproduce the expert-label aggregation, acceptance-rate calculation, and inter-rater agreement analysis reported in Table 6(a). Use the expert-reviewed SCA text files as reference data for inspecting extraction quality and evaluating outputs generated by alternative language models for Table 6(b).
