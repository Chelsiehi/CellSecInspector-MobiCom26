=== Connection: 2062 -> 2073 ===
From Event (2062):
Start State: UE is in 5GMM-CONNECTED mode over 3GPP access.
Condition: The UE receives an indication from the lower layers that the RRC connection has been suspended.
Action: The UE transitions from 5GMM-CONNECTED mode over 3GPP access to 5GMM-CONNECTED mode with RRC inactive indication.
End State: UE is in 5GMM-CONNECTED mode with RRC inactive indication.
To Event (2073):
Start State: UE is in 5GMM-CONNECTED mode with RRC inactive indication.
Condition: A trigger occurs to send a REGISTRATION REQUEST message with the NG-RAN-RCU bit of the 5GS update type IE set to "UE radio capability update needed".
Action: The UE moves to 5GMM-IDLE mode over 3GPP access and proceeds with the registration procedure for mobility and periodic registration as specified in subclause 5.5.1.3.2.
End State: The UE is in 5GMM-IDLE mode over 3GPP access and initiates the registration procedure for mobility and periodic registration.
